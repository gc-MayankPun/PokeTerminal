# PokeTerminal
> Turn your terminal into a Pokémon adventure every time you open it.

---

# Vision

PokeTerminal is **not another Fastfetch clone**.

Instead of displaying hardware information, PokeTerminal is a small terminal experience inspired by Pokémon.

Every time the terminal opens, you're greeted by a Pokémon encounter, complete with sprites, encounter rarity, forms, trainer information and eventually progression.

Think of it as a lightweight terminal RPG.

---

# Goals

- Beautiful startup screen
- Pokémon themed UI
- Minimal dependencies
- Fast startup
- Highly customizable
- Modular architecture
- Easy to extend
- Runs entirely in the terminal
